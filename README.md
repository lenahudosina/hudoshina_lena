# Сайт-лендинг — быстрый старт

Простой сайт на HTML/CSS/JS без сборки — можно запустить бесплатно за 5 минут через GitHub Pages, без кода и хостинга.

## Запуск через GitHub Pages (бесплатно, ~5 минут)

1. Зайди на github.com → создай новый репозиторий (например, `my-site`), публичный.
2. Загрузи в него 3 файла: `index.html`, `style.css`, `script.js` (кнопка "Add file → Upload files").
3. В репозитории: Settings → Pages → Source → выбери ветку `main` и папку `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу вида `https://твой-логин.github.io/my-site/`.

Захочешь подключить свой домен — тоже делается там же, в Settings → Pages → Custom domain.

## Что обязательно поправить перед запуском

1. **Телеграм и текст сообщения** — в `script.js`, в самом начале:
   ```js
   const TELEGRAM_USERNAME = 'lena_hudoshina';
   const PREFILLED_MESSAGE = 'Здравствуйте! Хочу обсудить проект.';
   ```
   Все кнопки "Обсудить проект →" ведут в Телеграм с этим текстом уже вставленным — заявки будут падать тебе прямо в личку, без форм и бэкенда.

2. **Фото** — сейчас вместо фото в кейсах и в блоке "Обо мне" стоят декоративные градиентные плашки (я не смогла выгрузить твои реальные картинки из Figma в этой сессии — доступ к файлам Figma был ограничен). Замени на реальные фото/скриншоты:
   - в `index.html` найди `case-card__media--betta`, `case-card__media--interior`, `about__photo`
   - проще всего заменить `<div class="about__photo"></div>` на `<img src="photo.jpg" class="about__photo" alt="Лена Худошина">` и добавить файл `photo.jpg` рядом с `index.html`.

3. **Email** — сейчас стоит `evkhudoshina@edu.hse.ru` (взяла из твоего Figma-макета), поменяй в `index.html`, если нужен другой.

4. **Текст "Обо мне"** — черновой, собран из фактов о тебе. Перечитай и поправь под свой голос.

5. **Отзывы** — блока отзывов в этой версии нет (в Figma был только пустой заголовок). Как появится текст отзыва от BETTA — скинь, добавлю блок.

## Структура

- `index.html` — весь контент и разметка
- `style.css` — стили (шрифты PT Mono + Inter, кремовый фон, чёрные кнопки — как в твоём Figma)
- `script.js` — аккордеон услуг, мобильное меню, ссылки на Телеграм

Аккордеон в разделе "Услуги" уже полностью рабочий: клик по услуге разворачивает/сворачивает описание, без плагинов и кода — это чистый JS.
